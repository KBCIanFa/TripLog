Yes — clearing browser storage will erase your trip data. Always export a JSON backup first (Settings → Export → Download Backup). The file is small and restores in seconds. Both apps remind you to back up periodically, and you can also export CSV for spreadsheet use.

Petrol or diesel only, want something simple? Get the Petrol & Diesel Edition (v1.2). EV, PHEV, or want lifetime trends? Get the Multi-Powertrain Edition (v2.2) — it includes everything the Petrol & Diesel Edition has, plus charging and analytics. When in doubt, go Multi-Powertrain.

The apps are HTML files that run locally — they don't need a server. A 404 usually means the file isn't in the same folder as this page, or it hasn't been uploaded yet. Use the ⬇ Download file button instead — save the HTML file to your device and open it directly in your browser. It will never 404 when opened locally.

Data doesn't sync automatically — each browser's storage is separate. To move data, export a JSON backup on one device and import it on the other (Settings → Import → Merge). Takes about 30 seconds. Most users log on their phone while driving and review the summary on their laptop.
